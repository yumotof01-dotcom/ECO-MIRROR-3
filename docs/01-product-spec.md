# 01｜製品仕様（Product Requirements v0.1）

## 一文の定義

**自然のつながりを、見る。試す。確かめる。** 実在する土地被覆データを起点に、植物被覆の構造的なつながりを可視化し、仮説条件による変化と仮想的な接続候補を、限界付きで比較できる科学学習・探究向けWebアプリ。

## 背景と解決したい問題

「植生が増えたから自然が改善した」「緑の区画があるから生き物が行き来できる」といった短絡的な解釈を避ける。地図上の植生分類、構造的な連結、生物の実測を分けたまま、**どこがつながり、条件で何が変わるのか**を利用者が確かめられるようにする。

## 想定ユーザー

- 高校生・探究学習：研究に必要な問い、仮定、図、限界、出典を理解する。
- 教員・指導者：同一条件で結果を再現し、データの根拠を確認する。
- 一般の興味関心層：複雑なネットワーク指標を地図の構造として理解する。

## MVPの必須機能

| ID | 機能 | 完了条件 |
|---|---|---|
| P01 | 地域を選ぶ | **事前計算済みで検証済みの6地域**の範囲から選択。出典・年・座標系を表示。任意地点は次段階。 |
| P02 | 地図レイヤー | ESA分類と植生候補の抽出結果を切り替え、欠損・不明値は明確に示す。 |
| P03 | シナリオの比較 | 440の固定条件から選択し、PCの計算結果と構造的なパッチ配置を比較する。 |
| P04 | モデル急変区間 | 40の曲線を見て最大低下区間・判定ルール・条件の違い・不確実性を読む。**生態学的閾値とは表示しない**。 |
| P05 | 自然の橋 | あらかじめ比較された候補と、追加面積400㎡、PC増分、パッチ結合・孤立の違いを示す。 |
| P06 | 根拠パネル | データ年、製品、ライセンス、派生ハッシュ、使った仮説、計算条件、未検証事項を必ず確認できる。 |
| P07 | 結果の保存 | 研究ID、データ版、選択条件、表示結果と注意事項をJSON・引用用テキスト等でエクスポートする（ライセンス表示）。 |
| P08 | 失敗・未接続 | 欠損/取得失敗/未計算/不適用/破損を明確に区別し、実測のゼロを偽装しない。 |

## MVPには含めない機能

- ログイン・会員管理・課金・生成AI API。
- 任意位置のリアルタイム衛星解析と未知の地域の生息確率予測。
- 緑化工事が可能な地点の推薦、土地所有者の推定、ハナバチの移動の断定。
- 生態系が絶滅する確率の推定。
- 旧ECO MIRRORの訪花観測不足シミュレーションの全面移植。**研究の紹介ページから旧版へリンク**するだけを初期範囲とする。

## 初期ユーザー体験

1. 地域を選ぶ。「ESA WorldCover 2021」「土地被覆分類であって生物観測ではない」が見える。
2. 植生候補レイヤーを有効化し、4/8近傍でパッチの違いを見る。
3. 仮想的な除去条件を変え、「同じ地図でも結果が変わる」を理解する。
4. 限界点の解析を表示し、判定が揺らぐ・実地実証がない理由も見る。
5. 接続候補地点を選び、PCが増える条件と**実際にパッチが結合する条件**を別表示する。
6. 根拠付きで結果を保存し、他者に再現可能な条件を共有する。

## 製品品質の基本条件

- 研究結果を見せる全画面でデータ来歴と「構造モデル／生物学的未検証」を確認できる。
- 図の色だけで正負や不確実性を区別しない。
- 初期表示が端末性能で極端に重くならないよう事前計算＋必要時のみ動的読込を優先。
- 無料枠の静的ホスティングでも公開できる構成を目標とする。ただしサービスの無料条件を公開前に確認する。

## リリース判断

**MVP完成 = 探究用に研究データを正しく探索できる**。**野外の保全施策が妥当 = 別の実測科学検証が必要**。この2つを分けて評価する。
