# 03｜UI・UX / ビジュアル設計システム

## コンセプト：「自然の見えないつながりを、見える問いに」

ECO MIRROR 3.0 は、一般的なダッシュボードの数字の羅列を避け、**1枚の地図と、自然のつながりを示す抽象的な表現**を中心にする。ただし「美しい演出で科学的な断定を偽装しない」が絶対条件。

### ビジュアル方向

- ベース：深いフォレストグリーン / ナイトネイビー。過度なネオンは使わない。
- 主役：緑地を土地被覆に即した色で示す。理論上のつながりは**破線**、現地観測を扱う場合は**実線と出典**。
- 温度感：落ち着いた研究所 + 生命力のある有機的な曲線。余白は広く、文字のコントラストを優先。
- 美的演出用背景は「装飾」でありデータ図と分離。装飾は aria-hidden にする。
- ライトモードは後から選択可能に。初期はダーク寄りだがコントラスト要件を守る。

### デザイントークン（草案）

`design/tokens.json` を正本とする。利用者のOS標準フォントで描画し、フォントの外部配信を必須にしない。

| 用途 | 草案 | 意味 |
|---|---|---|
| Background | #0A1518 | 地図を引き立てる最背面 |
| Surface | #102328 | 操作パネル |
| Foreground | #E8F3EF | 主本文 |
| Muted | #A5BEB7 | 補助本文 |
| Life | #69D2A6 | 植生候補の強調 |
| Analysis | #8EC5E8 | モデル上の関係 |
| Caveat | #F0C679 | 限界・不確実性 |
| Danger | #F09494 | 不正・計算失敗 |

### UI要素

- **Study Header**：地域、年、データ製品、処理状態、出典ボタン。画面から消えない。
- **Map Stage**：地図・凡例・パッチ識別。パッチを選ぶと地理・分類情報を開く。元分類とモデル関係を切替。
- **Scenario Rail**：λ、植生除去率、4/8近傍、分散/縁除去。事前計算済みの440条件を参照。
- **Threshold Curve**：モデル上の最大低下区間、判定ルール、他条件での安定性、未実証表示。
- **Bridge Inspector**：400㎡追加、実際のパッチ結合件数、孤立パッチ件数、PC増分を独立表示。
- **Evidence Drawer**：DOI、使用年、ライセンス、分類対応、座標系、研究ID、派生SHA256、未検証。
- **Results Export**：結果・出典・モデル版を一体で出力。

### アニメーションの規律

- 地図のモード変更に限定した短い遷移、原則 180–250ms。
- `prefers-reduced-motion: reduce` で演出を停止。
- PCが変化するアニメーションを、現地の動物が実際に飛ぶ動きに見せない。
- 気候や生物の変化が未計算なのに、未来の景観が成長する動画を生成しない。

### アクセシビリティ目標

- **WCAG 2.2 AA**を目指す（検証前に達成済みとは言わない）。
- スクリーンリーダー対応、キーボードだけでの基本操作、地図の表形式代替、図のテキスト要約。
- 最低44×44 CSS pxをタッチターゲットの設計目標とする（公式WCAGの要求サイズと混同しない）。
- レイヤーの違いを色だけで示さず、実線/破線/記号/説明文で重ねて示す。
- メッセージは「未接続」「取得失敗」「不適用」「計算できない」「計算完了」を区別し、色やアイコンだけに頼らない。

### プロトタイプ

`design/prototype.html` は、ここで述べたレイアウトを**データ未接続状態**として再現したもの。装飾的なラインは実測ネットワークではなく、見た目の試作である旨を明記する。科学的な数値・ランキングは表示しない。
