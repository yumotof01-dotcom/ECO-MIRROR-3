# 05｜科学的な正本とデータ契約

## 研究で区別する4層

1. **原データ**：ESA WorldCover 2021 v200、10mの土地被覆分類。観測年2021。
2. **構造的代理変数**：植生候補分類、4/8近傍のパッチ、面積と重心、距離減衰に基づくPC。実際の生物の動きを意味しない。
3. **仮説的な実験**：440の条件、仮想的な植生除去、同面積400㎡の仮想的な植生追加。実現確率を与えない。
4. **独立した実地証拠**：対象昆虫の移動・営巣・花資源・季節・道路の障壁・施工可否。**現段階では接続していない**。

**第2工程で、固定旧コミットの研究CLI16ファイルをバイト単位で一致させ、新旧の実データ数値全件一致を確認した。** ただしこの設計書のJSON Schemaは新UIの表示・保存用の草案で、実装済みの旧CLIデータ形式との互換性はまだ保証していない。研究計算をブラウザ画面には未接続。

## 440条件の参照実験

| 変数 | 値 | 種類 |
|---|---|---|
| λ（距離減衰の仮説パラメータ） | 40、60、90、135、200、300、450、675、1000、1500 m | 10 |
| 仮想植生減少率 | 0%〜50%、5%刻み | 11 |
| 連結パッチ | 4近傍 / 8近傍 | 2 |
| 除去規則 | distributed / edge_first | 2 |
| 合計 | **10×11×2×2 = 440** | 全列挙 |

さらに地域6か所＋追加4km範囲で3,080条件を計算した実績がある。**440以上を増やす場合は、追加の仮定を定義して新しい実験版（ID）を作り、全条件を監査する。無限・恣意的な列挙は行わない。**

## PCの意味

- 緑地候補パッチ i の面積 a_i、総研究面積 A を使う。
- 距離減衰 p_ij = exp(-d_ij / λ)。現研究実装ではパッチ重心間距離の近似を使用。
- PC = (Σ_i Σ_j a_i a_j p_ij) / A² （直線距離の減衰モデルの場合）。
- モデル内のPCの増加は**生態系の健康度や受粉成功率の増加率ではない**。
- 実移動を観測して検証したモデルではない。実験的な λ を野外の測定値として表示しない。

※ 旧実装の「相互接続 p_ij に最大積経路を使う」という第0工程の数式一般化と、重心距離ベースの第1工程で実装した**単純化された構造モデル**は同一の入力ではない。新アプリでは採用したモデルを明示する。

## モデル急変について

各 (λ、4/8近傍、除去規則) に対して植生減少率11点のPC曲線を1本とし、**40本**を調べる。どこで最大PC低下が発生したかを示す。急変の暫定フラグは研究上の診断であり、自然界の崩壊点を意味しない。

- 旧新宿2kmでは暫定フラグ1本。
- 旧新宿4kmでは暫定フラグ0本。
- どちらも外部の生物学的な限界点の実証ではない。観測領域・規則で結果が変化しうる。
- UIで「生態学的な限界点を発見した」とは表示しない。

## 「自然の橋」の定義

- 同じ面積の2×2画素・400㎡を、旧研究で元ESAコード50/60だった場所に仮想的に追加。
- PC増分だけでなく、追加前後の**緑地パッチの結合・変化なし・新たな孤立パッチ**の件数を別々に表示。
- 元水域、既存植生、不明分類を再分類して候補と偽らない。
- 旧研究では近くに別々のパッチがある656候補（新宿2km）の中から、16地点だけを440条件で比較。最適化済みの全候補という意味ではない。
- 計算上よい結果でも所有権、都市計画、環境影響・現地緑化可能性は未調査。

## 由来と真正性

- 全ての結果に製品名、データ年、データセットID、投影CRS、画素サイズ、派生画素SHA256、分類マスクSHA256、計算版、条件ID、実行日、検証状況を保持する。
- ESAの3度タイル全体のSHA256は、元研究では取得していない。**派生窓のハッシュを、全タイルのハッシュと表示しない。**
- 2020 v100と2021 v200はアルゴリズムが異なるため、地図の差分をそのまま真の土地被覆変化と呼ばない。
- 地理的な外周移動バッファが不足していることを、研究の詳細と出力に明記。
- 研究結果の元JSONのチェックサムを計算し、CIで再生成結果の一致を比較する。

## 状態の区別

| ステータス | UIの意味 |
|---|---|
| `not_loaded` | ファイルをまだ取得していない |
| `loading` | 正しいデータを読込中 |
| `structural_only` | 土地被覆に基づくモデル上の計算成功、実移動は未検証 |
| `not_estimable` | 欠損・上限・不整合などのため結果が得られない |
| `error` | 取得・権利・ハッシュ・版などの問題がある |

`structural_only` を「生態学的に検証済み」と解釈することは禁止。
