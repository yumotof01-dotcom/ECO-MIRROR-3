## 対象範囲

- React 19.3.1 / React DOM 19.3.1、React Router 7.18.4、TypeScript 7.0.2、Vite 8.3.4 の静的SPA骨格。
- Node 24以降・再現可能な npm package-lock v3。依存パッケージは旧研究のCIで実行済みの固定版を採用。
- 画面：ホーム `/`、研究モード切替 `/explore`、科学的な根拠 `/evidence`、不明URLの404。
- 探索は6研究地域から選択し、4研究モードを切替。選択はReactで管理、未接続の実データを読み込んだと偽装しない。
- 既存の静的設計プロトタイプを削除・改変せず、CSSを再利用してReact専用スタイルを追加。

## テスト・検証方法

```bash
npm ci
npm run design:check
npm test
npm run build
npm run preview
```

### 自動テストの対象

既存のNode設計テスト **5件**：
- 設計のみと研究計算の境界
- JSON schemaとモデルの科学的な未検証条件
- PC増分と緑地パッチ結合を区別する仕様
- 既存静的ワイヤーフレームのキー操作
- 研究出典と旧研究コミットSHA

新しいVitest + React Testing Library **5件**：
- ホーム→研究画面の遷移と未接続状態の明示
- 4タブのクリック・矢印・Home・End操作
- 地域変更時に旧地域の数値を流用しない
- 科学的な根拠と原データ出典の表示
- 存在しないURLでの明示的な404

## 合格条件／未確認を区別する

| 項目 | 現在の判定 |
|---|---|
| Node依存固定・インストール・型検査・静的ビルド | CIで合格 |
| React UIの状態遷移とアクセシブルなタブのDOM動作 | 自動テストで合格 |
| ルートへのHTTP応答とSPAフォールバック | CIのプレビュースモークテストで検査 |
| 旧設計の5テストと新しい5テスト | 10件をCIで検査 |
| 新しい研究データ／440条件の実行／橋のPC計算 | **未接続・未検証**（第2～3工程） |
| 地図のCanvasや実際の2021年WorldCover表示 | **未実装**（後工程） |
| WCAG 2.2 AAの完全適合、VoiceOver実機、iOS Safari、低メモリ端末 | **未検証** |
| コンテスト用の公開Webサイト | **未デプロイ** |
| 自然界の受粉・移動・保全効果 | **実証なし** |

**この第1工程は「アプリの骨格」を確認するゲートであり、現地の生態系の科学的検証ではない。**
