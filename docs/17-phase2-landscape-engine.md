# ECO MIRROR 3.0｜第2工程・検証済み研究エンジンの独立移植

記録日：2026-11-06。**ここでいう完成は研究CLIの移植を指し、公開Web画面で440条件を動かせることを意味しない。**

## 元データ・数理の正本

- 元リポジトリ：`yumotof01-dotcom/ECO-MIRROR`（旧アプリは変更しない）。
- 固定元コミット：`9a7fa63bc83f350c80ddf775124cd3cbeb6c112e`。
- 元の監査：[旧PR #20](https://github.com/yumotof01-dotcom/ECO-MIRROR/pull/20)。
- 新アプリ側：[元ファイルのGit blob記録](../provenance/legacy-import-manifest.json)。
- 取得元：**ESA WorldCover 10m 2021 v200**、CC BY 4.0、https://doi.org/10.5281/zenodo.7254221。
- 転写コード：`src/features/landscape/**` の純粋な計算モデル・元分類検証、`scripts/landscape/**` の土地被覆取込・研究実行・独立監査の**元々存在した16ファイル**。旧版のイベントデータ3,882件と旧React UIは移植していない。

## コードを変えず移植した範囲

| 研究関数 | 意味 | 科学上の禁止解釈 |
|---|---|---|
| `extractPatches` と `assessLandscape` | 仮想植生候補の連結・面積・重心距離によるPC | 昆虫の生息地・受粉率や実測移動確率ではない |
| `runExhaustiveScenarios` | λ10×仮想除去11×近傍2×規則2＝440条件 | 440の予測未来・発生確率ではない |
| `detectModelChangeIntervals` | 40本のモデル上の曲線における最大低下区間 | 生態系の絶滅・崩壊閾値ではない |
| `runBridgeExperiment` | 原分類50/60の2×2画素・400㎡追加を、各440条件で比較 | 施工可能性・土地の権利・生物の移動を証明しない |
| `verifyWorldcoverWindow` | 2021年データの宣言・マスクSHA-256・欠測分類の検証 | 2026年の最新地図やESA全タイルハッシュとは違う |

計算上の安全制限は元実装と同じで、最大4000の連結パッチ・100万セルを超える入力は適切に拒否。エラーを数値ゼロで穴埋めしない。**元コード本体は変更せず、各ファイルのGit blob SHA-1が完全一致している**。

## 独立したCIゲート

`.github/workflows/landscape-parity.yml` は以下を実行する。

1. 元リポジトリの**固定コミット**をCIの別ディレクトリ `.legacy-source/` にチェックアウト。移植した全16ファイルの **元のGit blob SHA-1とバイトSHA-256**を新旧で直接比較する。
2. 実際のESA WorldCover 2021を6地域・各200×200=40,000セル取得して同一のクロップを新旧の計算CLIに渡す。
3. 地域ごとに **440条件と40曲線**を新エンジンで計算。別言語Pythonで原分類・マスク・計算・全条件を監査する。
4. 同じ440条件を元の凍結CLIで実行し、出力報告の**全バイトが一致すること**を`cmp`で検査する。新宿2kmでは元監査結果のSHA-256とも照合する。
5. 地域ごとに**16地点×440条件＝7040件**の仮想的な前後比較を新エンジンで実行し、Pythonで独立監査。旧CLIでも再実行して結果報告の全バイトが一致することを確認する。
6. 新宿4km×4km＝**160,000セル**では440条件を新旧で比較し、元の固定結果SHA-256とも照合する。4kmの仮想介入は本監査の対象外。

合計予定：**ベースライン3,080条件、選択候補の前後比較42,240件**。4kmと2kmの窓は重なり、総40万セルは重複を含む延べ数。すべて実データ分類の構造モデルであり、実世界の生物移動を検証しない。

### 実行結果の保存

- `npm ci && npm run check`：従来設計テスト・React画面テストと旧研究エンジンのVitest回帰テスト。
- ワークフローが完了した場合、7地域窓のクロップおよび生成した全結果を**期限14日のActionsアーティファクト**として保存。
- 実データの取得と数値照合が全7窓成功するまでは**「完全移植確認」**と呼ばない。
- CIはオープンソースの公開リポジトリ上で実行。APIキー・常時有料サーバー・生成AI APIを導入しない。

## ブラウザへの接続は別工程

研究コードを新しい`src/features/landscape/`に取り込んでも**React画面はその計算をimportしていない**。端末上で毎回440×16回を直接同期計算すると、旧CIで最大300MiB超のメモリを消費していたため、今後は**監査済み結果の静的配布・遅延読み込み**を先に設計する。動的計算を公開する場合はWeb Worker＋処理中止＋旧リクエストIDの検証が必要。

地図の根拠を持たない「自然の橋を見つけた」といった表現や、現在の自然・昆虫の実移動の断定をUIに追加しない。

本変更は **Draft PR** として新リポジトリの第1工程ブランチの上に重ね、`main`や公開中のCloudflare production branchは変更しない。公開アプリの機能追加と本番公開は後工程でレビューする。
