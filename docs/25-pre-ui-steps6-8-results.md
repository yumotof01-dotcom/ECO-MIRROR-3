## 実ブラウザの証拠の保存

専用CIはChromium/Firefox/WebKitごとに3プロファイルを実行し、各90件、合計270件の保存結果を照合する。
ダウンロードしたJSONを実際のfile inputへ戻す。通信停止、改変、古い地域応答、取消、既存画面のキーボードと横方向のはみ出しも検査する。
ChromiumではCPU抑制下で20地図Workerを順次処理し、限定的なメインスレッドヒープ計測を行う。
詳しい定義は文書22、実際の数値はPR要約・CI成果物へ保持する。計測対象外のWorkerピーク・OS RSS・物理低RAM端末を測定したとは主張しない。
